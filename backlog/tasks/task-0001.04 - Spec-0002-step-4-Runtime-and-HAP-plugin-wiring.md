## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Runtime and every HAP pod run the hub, so both must follow plugin topics for plugin devices to reach automations, metrics and HomeKit, including when the runtime is down.

Scope:

- Add RBAC in `config/runtime/role.yaml` and `internal/render/hap.go`.
