## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The planner that turns a budget and rules into a day of blocks is the uncertain, algorithmic core of schedules; everything else feeds it, so it is built and proven first in isolation.

Scope:
Write `internal/schedule/plan.go`: budget, classification and block selection, with the unit tests above, including the property and brute-force tests. It has no API types yet, using its own `PlanInput`. This comes first because it's the uncertain, algorithmic core, and everything else feeds it.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Budget comes from bands (with missing or stale fallback), an expression, or none, clamped and rounded to slots
- [ ] #2 Slots classify with require over forbid over prefer, including windows that wrap midnight and day filters
- [ ] #3 Without a budget the plan is exactly the required slots
- [ ] #4 Plans never break minimum run, minimum rest, maximum starts or forbidden slots and never exceed the budget (property test)
- [ ] #5 Plans maximise score with deterministic tie-breaks, checked against brute force on small days
- [ ] #6 DST days plan correctly in Europe/Paris
<!-- AC:END -->
