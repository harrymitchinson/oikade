## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Room membership must be resolved at run time from hub.Store, so devices added to a room later are covered and a failing bulb does not leave the rest of the room on.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A room trigger fires on a change from any Device currently in the room, and not from other devices
- [x] #2 A room action sets every discovered member that reports the capability, in name order, and skips the rest
- [x] #3 A Device added to the room during a delay is included in later room actions of the same run
- [x] #4 A room action with no matching devices succeeds and logs at V(1)
- [x] #5 A partial failure in a room action lets the run continue and counts it as failed
- [x] #6 An in-process-broker test shows one room action producing a /set for every lamp in the room
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [x] #1 Tests pass
- [x] #2 Documentation updated

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. internal/hub/store.go: Store.Room(namespace, room) returns the declared Devices whose Meta.Room equals room, sorted by name. An empty room matches nothing. Add TestStoreRoom (new internal/hub/store_test.go).
2. internal/engine/compile.go: matches(device, room, capability) is true for a trigger naming the device, or naming the room that device is in now. A device with no room never matches a room trigger.
3. internal/engine/engine.go handle: look up the changed device's room once with Store.Get before the loop. trigger.device in CEL is unchanged.
4. engine.go execute: replace the step 1 skip with setRoom, which resolves members when the action runs. It skips undiscovered devices and devices without the capability, calls Set in name order, logs each failure with device, room and capability, and logs 'Matched no Devices in Room' at V(1) when nothing matched. A partial failure lets the run continue, and the run counts as failed at the end. Cancellation still returns cancelled. A failing device action still stops the run at once.
5. Unit tests in internal/engine: TestRoomTriggerMatches, TestRoomActionSetsMembers, TestRoomActionEmptyMatch, TestRoomActionPartialFailure, TestRoomMembershipAtExecution. The harness gains room/discovery fixtures, and fakeSetter gains per-device errors.
6. Integration: extend internal/runtime TestRuntimeEndToEnd. Add a second hallway lamp (a copy of the IKEA fixture with a new IEEE, built in the test so the shared driver fixture is untouched) and the desk plug in the hallway. A room-triggered Automation (front door in the porch) turns off the hallway lights; expect an OFF /set for both lamps and none for the plug.
7. make lint-fix (expected to be blocked by the golangci-lint/Go 1.27 mismatch; gofmt and go vet as fallback), then CGO_ENABLED=0 make test.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- Store.Room returns sorted declared members. An empty room name matches nothing, so roomless devices can't match.
- handle reads the changed device's room once per update with Store.Get. matches compares Device or Room against it, and trigger.device in CEL is still the device that changed (TestRoomTriggerMatches checks this through the condition).
- setRoom resolves members when the action runs. It skips undiscovered devices and devices without the capability, sets the rest in name order, logs failures with device, room and capability, and logs 'Matched no Devices in Room' at V(1). execute keeps going after a room partial failure and returns failed at the end. A cancelled context still returns cancelled, and device actions still stop the run on failure.
- The action unit tests call execute directly (it is synchronous) so they can capture logs with funcr at V(1). The trigger and membership tests use the harness with the fake clock.
- Integration: TestRuntimeEndToEnd adds a second lamp (a copy of the IKEA fixture made inside the test, leaving the shared driver fixture alone), desk-plug in the hallway, and front-door in the porch. A porch room trigger with a hallway room action produces an OFF /set for both lamps and no other commands.
- Verification: CGO_ENABLED=0 make test passes. The engine tests passed 5 times in a row with -count=5. go vet and gofmt are clean.
- Not verified: make lint-fix (golangci-lint can't read Go 1.27 export data) and go test -race (it needs CGO, and the macOS link fails here). Both are environment problems that also affect untouched code.
- Docs: doc comments on Store.Room, matches, execute and setRoom. The spec leaves the README to TASK-0002.04.
<!-- SECTION:NOTES:END -->
