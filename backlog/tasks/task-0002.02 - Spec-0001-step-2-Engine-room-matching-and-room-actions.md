## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Room membership must be resolved at run time from hub.Store, so devices added to a room later are covered and a failing bulb does not leave the rest of the room on.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A room trigger fires on a change from any Device currently in the room, and not from other devices
- [ ] #2 A room action sets every discovered member that reports the capability, in name order, and skips the rest
- [ ] #3 A Device added to the room during a delay is included in later room actions of the same run
- [ ] #4 A room action with no matching devices succeeds and logs at V(1)
- [ ] #5 A partial failure in a room action lets the run continue and counts it as failed
- [ ] #6 An in-process-broker test shows one room action producing a /set for every lamp in the room
<!-- AC:END -->
