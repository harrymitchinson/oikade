## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A misspelled room silently matches nothing at run time, so the manager must report it on the Automation and clear it when the Room appears.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 An Automation naming a missing Room shows Ready=False RoomNotFound listing the missing rooms
- [x] #2 Creating the Room flips the Automation to Ready=True without editing it
- [x] #3 A spec that fails to compile still reports Invalid rather than RoomNotFound
- [x] #4 The manager role grants get, list and watch on rooms
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. internal/controller/home/automation_controller.go: after a successful Compile, collect the distinct rooms named by triggers and set actions and list the Rooms in the namespace. If any are missing, set Ready=False RoomNotFound with 'Room(s) not found: a, b' (sorted). Invalid still takes precedence because the check runs only when Compile succeeds.
2. Add the RBAC marker for rooms get;list;watch, add Watches(&Room{}) mapped to every Automation in its namespace (automationsInNamespace, following BridgeReconciler.bridgesInNamespace), and run make manifests.
3. envtest in automation_controller_test.go, in a namespace of its own: missing rooms give RoomNotFound with a sorted message; creating them and reconciling again gives Ready=True, and the Room map function returns the Automation, which is what lets the watch re-reconcile it without an edit; a spec that doesn't compile and names a missing room reports Invalid.
4. Check config/rbac/role.yaml has rooms get, list and watch. make lint-fix (expected to be blocked by the environment), then CGO_ENABLED=0 make test.
<!-- SECTION:PLAN:END -->

## Implementation Notes

- automationsInNamespace follows BridgeReconciler.bridgesInNamespace. make manifests added rooms to the existing devices rule in config/rbac/role.yaml (get, list, watch).
- envtest (Ordered, in namespace 'rooms'): RoomNotFound with the sorted list; the message shrinks as Rooms are created; the Room map function returns the Automation, and the next reconcile gives Ready=True Valid; a bad value plus a missing room gives Invalid; a Room in another namespace maps to nothing.
- The watch is wired with the map function, which the envtest exercises. The suite has no running manager, so the event-driven re-reconcile is first exercised end to end in the Kind e2e in TASK-0002.04.
