## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A Go plugin needs a retained Last Will, a hook that re-announces on every connection, and a clean disconnect. internal/mqtt has none of these. This is the riskiest step, because the ordering bugs live here, so it goes first.

Scope:
- internal/mqtt/client.go: add Option, WithWill (retained, QoS 1, autopaho WillMessage), WithOnConnect (runs on every connection, after resubscribe completes, not in parallel with it), and Client.Disconnect (a clean DISCONNECT, so no Will).
- Connect stays source-compatible (variadic opts). Existing callers in cmd/ are unchanged.
- Tests use mqtttest: drop the connection without DISCONNECT to fire the Will, and restart the broker to prove OnConnect follows resubscribe.
- This assumes PR #16 (module path) has merged.
<!-- SECTION:DESCRIPTION:END -->
