## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Plugins are written in TypeScript to reuse existing protocol code, and plugins must not drift from the contract, so a shared SDK and an automated conformance check are needed.

Scope:
- The SDK goes in `sdk/typescript` (`@harrymitchinson/oikade-plugin-sdk`): it reads the environment, connects with the Last Will, publishes retained topics, and dispatches `/set`.
- Add `plugins/example-switch` (simulated) and `test/conformance` (a Go fake hub).
- Add a CI job in `.github/workflows/test.yml` that builds the Node workspace and runs conformance.
- Build plugin images for `linux/arm64` and `linux/amd64`.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Root Yarn 4 workspace (package.json, .yarnrc.yml, tsconfig.base.json, oxlint/oxfmt config) with workspaces sdk/typescript and plugins/*, matching ../homebridge-plugins. Build with tsc, test with vitest. Lint and format scripts are scoped to sdk/ and plugins/ so they never touch Go, YAML or Backlog files.
2. sdk/typescript (@harrymitchinson/oikade-plugin-sdk): readEnvironment, readDevices (contract 1), readSecret, relayCapability, and Plugin: retained offline Last Will, status online, retained devices/state/availability republished on every reconnect, /set validated against announced capabilities, offline on close. Unit tests with a fake connection.
3. plugins/example-switch: simulated relays following the relay convention.
4. plugins/Dockerfile: builds any plugin (ARG PLUGIN) for linux/arm64 and linux/amd64; tsc on the build platform, production deps on the target platform; non-root, exec-form CMD.
5. test/conformance (Go): fake hub on mqtttest with the real internal/driver/plugin decoder; runs OIKADE_CONFORMANCE_PLUGIN; checks announce, retained topics, /set round trips, SIGTERM, restart and Last Will with zero rejections. Skips without the env. make test-conformance.
6. CI plugins job in test.yml: make test-plugins, make test-conformance, buildx for both platforms.
7. Docs: SDK README, example-switch README, contract Conformance section.
<!-- SECTION:PLAN:END -->
