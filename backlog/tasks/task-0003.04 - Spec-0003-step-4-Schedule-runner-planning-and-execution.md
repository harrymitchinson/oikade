## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The runtime must plan each day, switch the target at block edges with the agreed safety rules, and keep the plan and credited runtime across restarts.

Scope:
- Write the `Loader`, the planning timer, the plan reuse on restart, precedence (plan only), the safety rules, crediting runtime, the status writer and `Planned`.
- Write `schedule.Collector`, and wire it into `internal/runtime/runtime.go`. Update RBAC in `config/runtime/role.yaml`.
- Add the unit tests and the `mqtttest` integration test.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Each planning day writes status.today and Planned; a restart the same day reuses the plan, runMinutes and starts
- [ ] #2 The target is switched at block edges via the bus
- [ ] #3 On is never sent while the target is unavailable, resting or at maximum starts; off is never blocked
- [ ] #4 Runtime is credited only while the target reports on and is available, checkpointed at most every 5 minutes
- [ ] #5 The schedule metrics are exported and the runtime role grants schedule access
<!-- AC:END -->
