## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Oikade's decoder and renderer each carry private copies of the oikade/v1 payload types, and the Go SDK would need a third. One public package removes the drift.

Scope:
- New contract/v1 (package v1): Contract, Online/Offline, the Env* constants, Root and its topic builders, ParseRoot, Status, Devices, DeviceReport, State, SetCommand, Payload, ParseSet, DevicesFile, DeclaredDevice. It imports nothing from api/ or internal/.
- internal/driver/plugin/instance.go uses them, and statusMessage and devicesMessage go.
- internal/render/plugin.go uses DevicesFile and the Env* constants, and PluginDevice and pluginConfig go.
- api/plugins/v1alpha1 (*Plugin).Topic() uses NewRoot. Run make manifests generate after the change; no CRD output should change.
- test/conformance switches to the shared types.
- .github/workflows/test-e2e.yml: add contract/** to paths.
- Risk: rendered devices.json bytes must not change, or every plugin pod restarts on upgrade. Add a golden test.
<!-- SECTION:DESCRIPTION:END -->
