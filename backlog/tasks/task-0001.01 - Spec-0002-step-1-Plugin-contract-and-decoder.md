## Implementation Plan

2. Add driver.Info.Error.

5. CGO_ENABLED=0 make test and lint.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Hub subscribes before SetDevices, and the broker replays retained topics in any order, so the decoder keeps each id's last raw state and availability and replays them once the id is declared and announced. Replays neither recount rejections nor log. Stats() (Up, Rejected by reason) is the pull-based hook for the step-4 collector. Set refuses when status is known offline or on a wrong contract. driver.Info.Error added; the status writer's PluginError reason is step 4. Verified: CGO_ENABLED=0 make test (all green, plugin 91% coverage), plugin tests -count=50 stable, make lint 0 issues.
<!-- SECTION:NOTES:END -->
