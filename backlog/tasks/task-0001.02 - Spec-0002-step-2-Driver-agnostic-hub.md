## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The hub hard-codes zigbee2mqtt.Instance and keys instances by bare NamespacedName, so a Plugin and a Zigbee2MQTT with the same name would collide. This refactor lets a second driver plug in without changing Zigbee2MQTT behaviour.

Scope:
Add `InstanceKey` and the internal `instance` interface in `internal/hub`, and thread `InstanceKey` through `Store`, `driver.Sink.Undeclared`, the metrics collector and `status`. Zigbee2MQTT behaviour is unchanged, and the existing tests stay green.
<!-- SECTION:DESCRIPTION:END -->
